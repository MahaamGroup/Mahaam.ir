# مشخصات فنی

- Next.js App Router، TypeScript strict، Node LTS و pnpm.
- Tailwind و tokenهای CSS variables؛ بدون inline styling برای تصمیم‌های طراحی.
- Server Components و caching پیش‌فرض؛ Client Component فقط برای تعامل.
- Zod برای قرارداد داده و validation سمت client/server.
- APIهای typed، پاسخ خطای ساختارمند و عدم افشای دادهٔ حساس.
- مسیرهای error/loading/not-found و logging حداقلی در production.
- محیط‌ها مستند، secretها خارج از repository و `.env.example` بدون مقدار واقعی.
