# ۱. شفافیت

مخاطب باید بداند:

- موضوع جلسه چیست.

---

«برای شناخت بهتر شرایط و فرصت‌های قابل توسعه، گفت‌وگوی تخصصی با گروه مهام آغاز می‌شود.»
