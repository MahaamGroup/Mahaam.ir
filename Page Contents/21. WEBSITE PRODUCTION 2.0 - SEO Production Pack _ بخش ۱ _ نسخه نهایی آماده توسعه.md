# SEO PHILOSOPHY

## هدف سئو مهام

هدف وب‌سایت، جذب ترافیک صرف نیست.

هدف، جذب مخاطب واجد شرایط (Qualified Intent) است.

بنابراین:

- کیفیت Intent از حجم Keyword مهم‌تر است.
- صفحات باید پاسخ‌گوی دغدغه مخاطب باشند، نه انبار کلمات کلیدی.
- معماری اطلاعات بر اساس Journey کاربر طراحی می‌شود.
- هر صفحه فقط یک Intent اصلی دارد.
