# Mahaam — Color System

## Palette intent

Use a composed, international palette based on deep ink, maritime blue, restrained indigo, warm off-white, and disciplined neutral gray. Accent color should behave like a point of direction, not decoration.

## Suggested tokens

| Token | Suggested value | Role |
|---|---:|---|
| Ink 950 | `#081525` | Hero and dark sections |
| Navy 900 | `#0C2340` | Primary dark surface |
| Deep Teal 700 | `#0D5A63` | Supporting depth / visual fields |
| Indigo 600 | `#3658B6` | Primary action and directional accent |
| Sky 300 | `#9FC9E8` | Soft highlight, dark-background detail |
| Ivory 50 | `#F8F6F1` | Warm primary light surface |
| Mist 100 | `#EEF1F3` | Secondary surface |
| Slate 500 | `#657080` | Secondary text |
| Slate 800 | `#253244` | Primary text on light surface |
| Success | `#227A5A` | Form success only |
| Warning | `#A76C16` | Form warning only |
| Error | `#B54045` | Form error only |

Values may be refined, but the palette logic must remain intact.

## Usage rules

- Primary text on light: Slate 800 or darker.
- Primary text on dark: Ivory 50.
- Indigo is reserved for CTA, active state, key links, and meaningful emphasis.
- Teal supports visual depth; do not turn it into a competing CTA color.
- Use tonal steps of one palette family before introducing a new hue.
- Gradients must be dark, low-saturation, and atmospheric; never rainbow.

## Contrast

All text and interactive states must meet WCAG AA. Do not put small text on bright gradients or photos without a controlled overlay.
