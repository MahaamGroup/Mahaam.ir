# Mahaam — Typography

## Typeface

Use `"IRANSans", Tahoma, sans-serif` throughout the Persian interface. Do not use decorative or novelty typefaces.

## Type character

Typography should feel editorial, precise, and comfortably readable. Let hierarchy come from scale, weight, measure, and spacing—not from excessive color or all-caps styling.

## Rules

- Right align all Persian prose.
- Avoid justified body text.
- Never center long Persian paragraphs.
- Headline line breaks must be intentional and balanced.
- Use bold only for meaningful emphasis; avoid mixing many weights in one block.
- Keep labels concise, letter spacing normal, and contrast sufficient.
- Use Latin words sparingly; when present, ensure harmonious baseline and direction behavior.

## Numerals

Use Persian numerals in user-facing content by default. Use Latin numerals only for technical identifiers, code, or internationally standardized data where necessary.
