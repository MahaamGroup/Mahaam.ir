# Mahaam — Visual Language

## Signature motifs

Use a small, repeatable vocabulary:

- **Path lines:** subtle directional arcs or segmented routes, representing exploration
- **Coordinate fields:** low-contrast dots, axes, or grid intersections, representing orientation
- **Layered planes:** overlapping surfaces, representing multiple conditions and perspectives
- **Light horizon:** diffuse gradient bloom, representing a possible next step
- **Information markers:** refined labels and small index numerals, representing clarity

Use no more than two motifs in one section. Motifs must remain subordinate to content.

## Surface language

Important content appears on purposeful surfaces:

- Large content panels with warm-white or dark-toned backgrounds
- 1px low-contrast borders
- Radius that feels architectural: rounded, never cartoonish
- Soft elevation that increases on interaction
- Occasional translucent surface only on dark atmospheric backgrounds

## Information density

The site must feel considered, not sparse. Combine concise Persian copy, small contextual labels, visual anchors, and interactive cues. Never use decoration to compensate for missing hierarchy.

## Contrast language

- Dark fields create focus and authority.
- Light fields support reading and comparison.
- Accent color identifies action or a meaningful connection.
- Do not use color as the only differentiator between categories.

## Persian interface rules

- All primary composition flows right-to-left.
- Keep long Persian paragraphs narrow and right aligned.
- Use Arabic/Persian numerals consistently in user-facing copy, unless a technical label requires Latin.
- Do not mirror icons that have universal direction only when doing so harms meaning; arrows and progress directions should follow RTL.

## Textural rules

Noise, mesh, grain, and grid treatments must be almost felt rather than consciously noticed. They should disappear behind text at normal viewing distance.
