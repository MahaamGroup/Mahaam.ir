# Mahaam — Iconography

## Style

Use a consistent outline icon family with a 1.5–2px rounded stroke. Icons should feel precise, minimal, and quietly technical.

## Principles

- One icon family only
- Consistent optical size and stroke weight
- Rounded line endings, restrained geometry
- Use a limited number of icons; text remains the primary carrier of meaning
- Icons may sit in subtle circular or squared containers only where grouping requires it

## Direction and RTL

Directional arrows, progress marks, and navigation chevrons must respect RTL flow. Icons with universal fixed meaning should remain semantically correct.

## Colors

Use Slate 800 or muted Navy on light backgrounds; Ivory or Sky 300 on dark backgrounds. Indigo is for active / interactive emphasis only.

## Avoid

- Emoji
- Filled multicolor illustrations masquerading as icons
- 3D icons
- Unrelated icon styles in the same interface
- Decorative icons beside every line of text
