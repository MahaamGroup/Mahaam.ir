# Mahaam — Layout System

## Desktop grid

- 12 columns
- Maximum content width: 1320px
- Desktop outer padding: 48–72px
- Column gutter: 24px
- Main section vertical spacing: 112–160px
- Large page top/bottom spacing must feel generous, not wasteful

## Breakpoints

- Mobile: 0–639px
- Tablet: 640–1023px
- Laptop: 1024–1279px
- Desktop: 1280–1535px
- Wide: 1536px and above

## Responsive principles

- Build the hierarchy for desktop, then preserve it on tablet and mobile.
- Do not simply shrink desktop; recombine layouts intentionally.
- Use one column for dense card collections on narrow mobile screens.
- Keep the primary CTA accessible without making every element sticky.
- Preserve section atmosphere using lighter assets or simplified motifs where necessary.

## Header

The header begins integrated into the hero. On scroll, it becomes a compact, solid, sticky surface with a subtle border and restrained backdrop blur.

RTL navigation:

`خانه | مخاطبان | مسیرها | ارزیابی مسیر | مهام چگونه کار می‌کند؟ | درباره مهام`

Primary CTA: `شروع ارزیابی مسیر`

## Section anatomy

Each section has a deliberate sequence:

1. Eyebrow or index label (optional)
2. Persian headline
3. Supporting explanation
4. Primary visual or interaction
5. A singular next action, only when appropriate

Avoid placing a heading, paragraph, three cards, and button in the same repeated template for every section.

## Reading measure

- Body copy max: approximately 58–68 Persian characters per line
- Headline max: 2–4 balanced lines on desktop
- Avoid centered long-form Persian text

## Footer

Use a dark, spacious footer divided into meaningful navigation columns: Mahaam, audiences, pathways, and resources. Include placeholder contact information, legal links, and understated social placeholders.
